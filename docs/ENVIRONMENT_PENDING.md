# 环境向量设计待确认

**状态：有问题待讨论，暂不修改。**

目前保留的 `trend_v3` 实现将四个变化指标及四个有效性标记编码成 64 维 `e`：评论活动变化、价格变化、价格波动变化、价格有效覆盖率变化。评论活动来自已提交的模拟评论，不是可靠的真实成交量。

尚未解决的是：这些输入及其进入 Attention 的方式，是否能恰当地表达“当前市场相对往常，让用户更愿意或更不愿意投入注意力”。不能把现有结构、默认版本或链路运行成功视作该设计已经确认。

现阶段优先确认市场环境和 query 能正常调用、返回与源资料相符的内容，并明确区分合法空值与调用失败。向量算法、Attention 作用方式、指标选择留待后续讨论。

本独立目录只进行模块抽取、路径参数和工程结构调整，没有修改四阶段画像、环境向量计算、动态 Lambda 或三 head 的算法。
